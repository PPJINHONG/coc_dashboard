# 관리자 DB 관리

개발 모드에서도 실제 로그인한 활성 관리자만 DB 관리 탭과 `/api/db-admin/`를 사용할 수 있습니다. 일반 운영 화면은 개발용 로그인 우회를 유지하며 DB 관리에는 적용하지 않습니다.

## 본문 위 가로 탭

- **공통데이터**: 리전·서비스·인력을 하위 탭으로 선택해 등록·수정·삭제합니다. 전체 또는 일부 기능에서 같은 원본을 참조하며 사용 상태 구분은 없습니다.
- **기능별 설정**: 인프라 자원, 운영 인력, 운영 작업, 리전 이슈, 이슈 댓글, 사용자·권한을 하위 탭으로 관리합니다. 공통데이터 목록을 입력 화면에 반복해서 표시하지 않습니다.
- **DB 원본**: 실제 사용하는 업무·사용자 테이블을 읽기 전용으로 조회합니다.

일반 운영 탭에서는 관리자도 조회만 가능합니다. 실제 활성 관리자만 DB 탭의 설정 화면에서 입력·수정·삭제하며, 개발용 로그인 우회도 쓰기 권한을 부여하지 않습니다.

공통데이터에서 리전을 추가하면 같은 DB 원본과 기능별 리전 선택 목록에 반영됩니다. 인프라 수량은 Host·VM·Storage만 입력합니다. Compute 랙의 열과 기존 값은 제거했습니다.

사용자·권한 설정에서는 이메일 아이디·이름·비밀번호·활성 상태·일반/관리자 권한을 관리합니다. 새 비밀번호는 검증 후 해시로 저장하고 조회·이력에는 반환하지 않습니다. 현재 관리자 자신과 최고 관리자를 비활성화·일반 사용자로 변경·삭제할 수 없습니다. `/api/me/`도 조회만 제공하므로 계정 수정은 이 설정에서 처리합니다. 회원가입과 로그인은 유지합니다.

## 원본 테이블 조회

웹에서 사용하는 9개 업무·사용자 테이블만 허용 목록으로 표시합니다. 목록은 `database_admin/catalog.py`의 `TABLE_LABELS`에서 관리합니다. 인증 세션·마이그레이션·사용하지 않는 게시판/대시보드·감사 내부 테이블은 제외합니다.

데이터 검색·정렬·페이지 조회, 열·자료형·기본값·기본키·외래키·제약조건 조회를 제공합니다. **원본은 모두 읽기 전용**이며 행 추가·수정·삭제나 열·테이블 구조 변경 API는 없습니다. 비밀번호 등 민감한 값과 기본값은 숨깁니다.

## API

- `PUT /api/db-admin/sections/{section}/`: 기능별 최신값 저장.
- `POST /api/db-admin/common/{collection}/`, `PATCH/DELETE /api/db-admin/common/{collection}/{pk}/`: 공통데이터 관리.
- `POST /api/db-admin/issues/{id}/comments/`: 이슈 화면에서 댓글 입력.
- `GET /api/db-admin/`: 허용된 업무·사용자 테이블.
- `GET /api/db-admin/tables/{table}/`: 구조.
- `GET /api/db-admin/tables/{table}/rows/`: 원본 조회. 쓰기 요청은 405.
- `GET/POST /api/db-admin/accounts/`, `PATCH/DELETE /api/db-admin/accounts/{id}/`: 계정·권한 관리.
- `GET/POST /api/db-admin/comments/`, `PATCH/DELETE /api/db-admin/comments/{id}/`: 댓글 관리.
- `GET /api/db-admin/changes/`: 관리자 계정·댓글 변경 이력.

쓰기에는 CSRF 토큰과 관리자 세션이 필요합니다. 운영 데이터의 상세 구조와 최신값 이전 정책은 [운영 데이터 설계](operations.md)를 참고하세요.

## 행 복사

공통데이터와 기능별 설정의 행 복사는 새 편집 초안을 만듭니다. 저장 전 원본 DB는 바뀌지 않습니다. 공통데이터는 새 코드를 입력하고 필요한 이름을 변경합니다. 인프라는 리전·서비스·환경, 작업은 리전·구분·대상, 운영 인력은 성명 등 고유 조합을 확인한 뒤 저장합니다. 중복 조합은 서버에서 원자적으로 거절합니다. 이슈를 복사할 때 기존 댓글은 복제하지 않습니다.

댓글·계정에도 복사를 제공합니다. 계정 비밀번호는 복제하지 않으며 새 아이디·비밀번호를 직접 입력합니다. 복사한 계정의 기본 권한은 일반 사용자입니다. 원본 DB 탭은 복사·쓰기 없이 읽기 전용을 유지합니다.
